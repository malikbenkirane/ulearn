# Helix: Inserting Literal `<` and `>` in Key Remapping Macros

In Helix, key remapping macros (prefixed with `@`) use angle brackets `<>` to denote modifier+key combinations like `<C-w>` (Ctrl+W) or `<A-o>` (Alt+O).

**Problem**: How do you insert a literal `<` or `>` character in a remapping macro?

**Solution**: Use their named key representations wrapped in angle brackets:
- `<` → `<lt>` (less than)
- `>` → `<gt>` (greater than)

**Example**:

```toml
[keys.normal]
"@key" = "@<lt><A-x><gt>"
```

This types `<`, then executes Alt+X, then types `>`.

**Why**: Without this naming, the parser would interpret `<>` as a malformed modifier wrapper and fail.
